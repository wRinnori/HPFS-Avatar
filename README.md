# HPFS-Avatar

Official implementation of **Hierarchical Progressive Fusion with Part-Aware Learning and Post-Skinning Residuals for Emotional Speech-Driven Avatars**.

## Status

The source code, configuration files, pretrained models, and usage instructions are currently being organized and documented.

The complete implementation will be released after code cleanup.

## Data Preparation
Please download the [BEATv2](https://huggingface.co/datasets/pliu23/BEATv2) choose the English data v2.0.0. 
Download the [X-Humans](https://github.com/Skype-line/X-Avatar) datasets from their official sources.
